Claude יבדוק ויתקן.

הסקיל סורק פרויקט אינטרנט לפי תקן ישראלי 5568 ותקנות נגישות השירות, מפיק דוח מסודר עם קובץ ושורה לכל בעיה, מתקן אוטומטית את מה שבטוח לתקן ומציע פתרון מדויק לכל השאר.

הורדת הסקיל (‎.skill) קוד המקור ב-GitHub

עובד עם HTML/CSS/JS, ‏React/Next.js, ‏Vue ו-Svelte. ללא תלויות חיצוניות.

איך זה עובד

מבקשים מ-Claude לבדוק נגישות, והסקיל מנחה אותו בארבעה שלבים.

  1. סריקה

    סקריפט קריאה-בלבד עובר על קובצי HTML, ‏JSX, ‏Vue ו-CSS ומאתר הפרות.

  2. מיון

    כל ממצא מסווג: האם יש לו תיקון אחד ויחיד ונכון, או שהוא דורש החלטה אנושית.

  3. תיקון

    רק תיקונים חד-משמעיים מיושמים בקוד. תוכן כמו טקסט חלופי או צבעי מותג לא מנוחש.

  4. דוח

    נוצר accessibility-report.md בעברית, ממוין לפי חומרה, עם הפניה לסעיף התקן.

מה נבדק

קריטריוני WCAG 2.0/2.1 ברמת AA שעליהם מבוסס התקן הישראלי, ועוד דרישות שייחודיות לישראל.

התקנה

בוחרים את הסביבה שבה עובדים עם Claude.

Claude.ai או אפליקציית Claude

  1. מורידים את קובץ הסקיל.
  2. נכנסים להגדרות, ובחלק של הסקילים (Skills) מעלים את הקובץ.
  3. מבקשים מ-Claude לבדוק נגישות של פרויקט.

Claude Code

מעתיקים את תיקיית הסקיל לתיקיית הסקילים של המשתמש:

git clone https://github.com/jordanhemo/il-accessibility-audit.git
cp -r il-accessibility-audit/il-accessibility-audit ~/.claude/skills/

נדרש Python 3. אין חבילות נוספות להתקנה.

איך מבקשים

אין צורך לזכור שם של פקודה. מספיק לכתוב בשפה חופשית, למשל:

  • תבדוק אם האתר בתיקייה הזו עומד בתקן הנגישות הישראלי ותתקן מה שאפשר
  • אני צריך דוח נגישות לפי תקן 5568 לפרויקט ה-Next.js שלי
  • חסרה לנו הצהרת נגישות? תכין לי אחת

חשוב לדעת

הסקיל מבצע סריקה סטטית של קוד המקור. הוא מוצא את רוב בעיות המבנה והסימון, אבל לא רואה תוכן שנוצר בזמן ריצה, ולא מפענח משתני CSS או ירושת צבעים.

הדוח הוא כלי עזר ואינו מחליף בדיקת נגישות מקצועית או ייעוץ משפטי. לאישור עמידה בתקנות מומלץ לשלב בודק נגישות מוסמך ובדיקה עם משתמשים אמיתיים.

הצהרת נגישות של עמוד זה

העמוד נבנה בהתאם להנחיות WCAG 2.1 ברמת AA: שפה וכיווניות מוגדרות, קישור לדילוג לתוכן, ניווט מלא במקלדת עם סימון מיקוד ברור, ניגודיות צבעים תקינה במצב בהיר וכהה, וכיבוד הגדרת הפחתת תנועה.

נתקלת בבעיית נגישות? אפשר לדווח דרך דף הדיווח על תקלות ב-GitHub.
